Employee Management System

A Flutter application for HR teams and managers to manage employee records, attendance, and workflows with a polished mobile experience.

App Links Back to Portfolio

Overview

This project centralizes employee data and attendance tracking inside a single mobile experience. It provides HR users with quick access to employee profiles, attendance records, and workflow summaries.

Problem Solved

Manual employee management creates duplicate records, missed attendance updates, and low visibility into workflows. This app simplifies those processes and helps teams keep accurate information in one place.

Key Features

  • Employee profile management with searchable records
  • Attendance history and daily status tracking
  • Workflow dashboards for task and approval updates
  • Responsive mobile screens for Android and iOS

What I Built

I created the complete mobile UI using Flutter, integrated REST APIs to load and update employee data, and added validation and error handling for smoother user interactions.

  • Designed reusable Flutter widgets for employee cards and attendance views
  • Connected app screens to backend services for real-time data updates
  • Improved loading performance and reduced UI jank during navigation
  • Tested across multiple device sizes to keep the interface consistent
